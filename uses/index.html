Software I use

Szoftverek, amiket használok

I value privacy, I hate monopolies, I usually prefer open source. I gravitate toward tried and tested (or "boring") technology. I like when software stays out of the way and hate it when it annoys me with bullshit.

Fontosnak tartom az adatvédelmet, utálom a monopóliumokat és igyekszem főleg nyílt forrású szoftvereket használni. Általánosságban a jól bevált (avagy "unalmas") technológiákat preferálom. Szeretem, ha egy szoftver nincs útban és utálom, ha hülyeségekkel traktál.

Firefox and és ("Ungoogled") Chromium

My daily driver is Firefox, but for playing and making browser games I use Chromium, usually the "Ungoogled" version. I use a number of browser extensions to make the Internet suck less: Alapvetően Firefox-ot használok, de böngészős játékokhoz (és azok fejlesztéshez Construct-ban) Chromium-ot használok, mostanában az "Ungoogled" változatot. Ezeket a bővítményeket mindig felteszem és beállítom:
uBlock Origin, News Feed Eradicator, ClearURLs, Redirector (to forward twitter.com and x.com URLs to xcancel.com, etc) (twitter.com és x.com URL-ek átirányítása az xcancel.com-ra, stb.)

Windows 10 LTSC

Obtaining this version is not very straitforward (thanks, Microsoft), but the Home/Pro versions would drive me up the wall. The LTSC version still receives security updates until 2027, but I'll probably look into alternatives soon as I have no intention to use Windows 11. I've used macOS and various Linux distros in the past; Linux Mint, Manjaro and KDE Neon were pretty good daily drivers for me.

A beszerzése meglehetősen cseles (kösz, Microsoft), de a Home/Pro verziótól falra másznék. Az LTSC verzió 2027 januárjáig kap biztonsági frissítéseket, így hamarosan alternatívát kell rá keresnem, mert a Windows 11-et nem szeretnék. Korábban használtam már macOS-t és mindenféle Linuxokat, leginkább a Linux Mint, a Manjaro és a KDE Neon disztrókat találtam munkára alkalmasnak.

Visual Studio Code / VSCodium

I used NetBeans to write HTML, CSS, JS and PHP for about 15 years, then I found an acceptable SFTP extension for VSCode.

15 év NetBeans használat után váltottam rá, miután találtam hozzá egy úgy-ahogy jól működő SFTP plugint. HTML, CSS, JavaScript és PHP kódoláshoz használom.

Construct 3

The game engine that clicked for me. Runs in the browser, great for making 2D and 2.5D games. I've been hooked on it since 2020.

Kezdőbarát engine elsősorban böngészőben futó 2D és 2.5D játékok fejlesztéséhez. 2020 óta rá vagyok csavarodva.

Publii

An open source cross-platform CMS with a very nice GUI. It generates static sites that you can host basically anywhere, and are a lot harder to hack or slow down compared to server side rendered ones.

Nyílt forráskódú és platformfüggetlen tartalomkezelő rendszer, kényelmes grafikus felülettel. Statikus weboldalakat generál, ami jelentősen egyszerűsíti a hosztolást és az üzembiztos működést.

Utilities

Segédprogramok

  • Scoop: a package manager for Windows. I install and update most programs with this. csomagkezelő, a legtöbb prorgramot ezzel telepítem és frissítem.
  • OneCommander: an excellent replacement for the Windows File Explorer, comes with tabs and a lot of other features. Windows Intéző helyett, vannak benne fülek meg egy rakás hasznos funkció.
  • Notepad++: a powerful notepad.exe replacement for writing, making todo lists and some light coding. jegyzettömb, csak sokkal jobb. Munkához és hobbi projektekhez is rengeteget használom.
  • SimpleWall: a lightweight application firewall for Windows to block network access of programs I prefer to keep offline. alkalmazás tűzfal, amivel le lehet tiltan programok ill. szolgáltatások hálózati elérését.
  • 7-Zip: powerful and fast archiving utilty. mindentudó nyílt forrású tömörítőprogram.
  • MPC-HC: a very good video player. kiváló videólejátszó.
  • XMPlay: to play music (including tracker tunes). kiváló zenelejátszó (trackelt cuccokhoz is).
  • ImageGlass / qView: good image viewers. képnézegető programok.
  • qBittorrent: to download Linux ISOs. Linux ISO-k letöltéséhez.

Services I use

Szolgáltatások, amiket használok

Dropbox

I use three different PCs in rotation, I sync my work projects and files on my desktop with Dropbox.

Három PC-t használok felváltva, a Dropbox szinkronizálja közöttük az asztalom és a projektmappáim tartalmát.

Startpage

My main search engine, essentially a proxy for Google. Also removes a lot of bullshit from the results page.

Az alapértelmezett keresőmotorom. Google találatokat jelenít meg, de a böngészőm így nem kommunikál a Google szervereivel (és nincs egy rakás baromság a találati oldalakon).

Discord, Telegram and és Bluesky

I deleted my Facebook and Instagram accounts in 2025 and I don't intend to go back. I found great communities on Discord, I talk to my friends on Telegram and I occasionally use Bluesky to post about gamedev and discover fellow creators.

2025-ben megszüntettem a Facebook és Instagram fiókjaimat és nem is tervezek visszatérni. Online közösségi életet Discordon élek, ismerőseimmel Telegramon kommunikálok, a Bluesky-t szinte kizárólag játékfejlesztéssel kapcsolatos posztolásra és tartalom-felfedezésre használom.
